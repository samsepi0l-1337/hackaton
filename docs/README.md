# docs

ICT INNOHACK 2026 (동남권 이노베이션 해커톤) 참가 자료와 서비스 기획 문서 모음.

## 서비스: 해보까

운영 주소: https://haeboka.dreamp.org

부산에서 창업하려는 청년이 관심과 상황을 입력하면, AI 창업 상담이 쉬운 질문으로 구상을 정리하고 준비 안내와 지금 신청할 수 있는 지원사업을 근거와 함께 알려준다. 모집 중인 공고는 지원서 초안을 만들어 볼 수 있다. 초안은 사용자가 확인한 뒤 모의 제출까지 하고, 실제 신청은 공식 사이트에서 한다.

### 주요 결정

- 로그인: 이메일·비밀번호
- 배포: Cloudflare Workers Paid($5/월) 포함 사용량 안에서, 초과 과금 금지
- 자격 판정은 규칙, 설명·대화만 AI. 관련도 점수는 jev 공개 서비스
- 지원서 작성: 공고 양식을 DocWorker 컨테이너에서 내려받아 Document Parse 로 읽고, Solar 가 신원 정보가 아닌 칸의 초안을 쓴다. 제출은 모의 제출까지만 한다. 실제 신청은 공식 사이트에서 한다.
- 백엔드는 Rust → WebAssembly Cloudflare Worker 하나 (`apps/api-rs`)
- 부산시·구·대학 자체 공고는 시간이 남으면(P2)

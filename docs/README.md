## 서비스: 부산 청년 창업 길잡이 (가칭)

부산에서 창업하려는 청년이 사업과 타겟 고객 정보를 폼으로 넣으면, AI 멘토가 되물어 아이디어를 다듬고 지금 신청할 수 있는 부산 창업 지원사업 Top3를 근거와 함께 알려준다. 사용자가 승인하면 AI 에이전트(Cloudflare Agents)가 공고 양식을 내려받아 작성하고 지원서를 제출한다.

### 주요 결정

- 로그인: 이메일·비밀번호
- 배포: Cloudflare Workers Paid($5/월) 포함 사용량 안에서, 초과 과금 금지
- 자격 판정은 규칙, 설명·대화만 AI. 관련도 점수는 jev 공개 서비스
- 자동 제출: 공고마다 올라온 양식을 Container에서 내려받아 작성, 사용자 승인 후 제출
- 부산시·구·대학 자체 공고는 시간이 남으면(P2)

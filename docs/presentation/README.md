# 발표 자료

## 다시 만들기

`pptxgenjs`가 설치된 환경에서 다음을 실행합니다.

```sh
cd docs/presentation && bun build.mjs
```

`gil-pitch.pptx`가 생성됩니다. 슬라이드 발표자 노트는 `script.md`의 각 문단에서 가져옵니다. 첫 장의 `[팀명]`을 실제 팀명으로 바꾸고 다시 빌드하세요.

## 제출

발표 자료는 **PDF만** 제출할 수 있습니다. PowerPoint 또는 호환 프로그램에서 PPTX를 열어 PDF로 내보내고, 글꼴·레이아웃과 모든 페이지가 정상인지 확인하세요. 파일 제목에 팀명을 넣어야 합니다: `TODO-팀명-gil-pitch.pdf`의 `TODO-팀명`을 실제 팀명으로 바꾸세요. 2분 발표 후 4분 테이블 시연이 예정되어 있습니다.

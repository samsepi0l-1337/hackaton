# Solar 독립 평가 (2026-11-27)

운영 코드가 부르는 Solar 기능이 맞는 답을 내는지, 손으로 붙인 정답과 비교했다.

- 실행: `EVAL_DEV_VARS=<.dev.vars 경로> bun run --cwd apps/api eval:solar`
- 코드: `apps/api/scripts/eval/run.ts`
- 정답: `apps/api/scripts/eval/labels.json`
- 결과: `apps/api/scripts/eval/results.json` (마지막 실행)

## 방법

- **자료:** 운영 공고 111건 중 30건(`data/postings.json`, 2026-11-27 수집)과 가상 사용자 11명. 실제 계정 정보는 쓰지 않았다.
- **정답:** 모델을 돌리기 전에 공고 제목·대상·내용만 읽고 손으로 정했다. 사용자별로 관련 있는 공고(1~4건)와 공고별 유형을 붙였다. `capabilitiesOf`·`recommendResources` 결과는 보지 않았다. 정답 파일은 따로 먼저 커밋했다(5a462f2).
- **같은 경로:** 운영 모듈을 그대로 불렀다. 관련도는 `createDecide`, 추천 이유·질문 말투·요약 칸은 `exploreAi` (`reason`·`question`·`fill`)다. 모델·시간 제한·사실 검사(guard)도 운영과 같다. Upstage 는 게이트웨이를 거치지 않고 직접 불렀다.
- **비교 기준:** 규칙 추천(`recommendResources`)과 무작위 선택.
- **호출 수:** 2회 실행에 186회(한도 300회)를 썼다. 비용은 약 $0.05 이하로 추정한다(Decide flash, Solar Mini 할인가, Solar Pro 12회).

## 결과

### 1. 관련도: Solar Decide (후보 26건 중 상위 3건)

| 방식 | P@3 | 적중(상위 3건에 정답 1건 이상) | 재현율@3 |
|---|---|---|---|
| Decide, 운영 입력 형식 | **0.42** | 10/11 | 0.68 |
| Decide, 나이·거주지·사업자 추가 | 0.42~0.48 | 11/11 | 0.67~0.74 |
| 규칙 (`recommendResources`) | 0.09 | 3/11 | 0.11 |
| 무작위 | 0.09 | — | — |

- 정답 수가 사용자마다 1~4건이라 P@3 의 최대값은 0.73이다.
- **1위:** 2회 실행 모두 11명 중 10명에서 1위가 정답이었다. 1위 공고는 두 실행이 같았다.
- **지연:** p50 0.9~1.1초, p95 1.9~2.8초다. 시간 제한은 3초이고 실패는 0회였다.
- **약점:**
  - 2·3위에 특정 공고(디자인 교육 P2, 오픈이노베이션 P4)가 자주 끼어 정답과 관계없이 나온다.
  - '기초부터 배우고 싶다'는 사용자 G 는 운영 형식에서 정답을 하나도 찾지 못했다. 정보를 더한 입력에서는 원스톱 상담(P25)을 찾았다.
- **규칙이 약한 이유:**
  - K-Startup 공고에는 '아이디어 없음(no_idea)' 단계가 없어, 사용자 G 의 추천이 비었다.
  - 나머지 사용자는 원하는 도움 종류만 맞으면 같은 3건(P28·P18·P26 또는 P26·P25·P22)을 받았다.
- **중요:** 지금 창업 준비 결과(`/api/explore/result`)는 Decide 를 쓰지 않는다. 규칙 추천만 쓰고, Decide 는 예전 `/api/recommend` 에만 연결돼 있다.

### 2. 추천 이유: Solar Mini (`exploreAi.reason`, 24건)

| 항목 | 결과 |
|---|---|
| 실패·시간 초과 | 0 / 0 |
| 사실 검사 탈락 | 0 |
| 기관 이름 언급 | 0 |
| '이 지역이라서' 식 이유 | 0 |
| 공고에 없는 숫자 | 2 (모두 사용자 입력의 업력, 예: '창업 3년 차'). 지어낸 금액·날짜는 없음 |
| 160자 넘어 잘림 | 5 (문장 끝에서 자름) |
| 지연 | p50 0.3~0.4초, p95 0.55초 |

- 공고 내용과 사용자 상황을 이어서 쓴다. 예: AI 숏폼 교육(P11)에서 "이 교육으로 AI 영상 제작의 기초를 익히고, 아이디어를 어떤 사용자가 실제로 쓸지 점검하는 데 써 보세요."
- 공고에 없는 일반 조언(R&D·비R&D 구분 등)을 덧붙이는 경우가 있다. 사실 검사는 금액·날짜·사업명만 보기 때문에 이런 문장은 막지 못한다.

### 3. 질문 말투: Solar Mini (`exploreAi.question`, 11건)

기준 질문: "그 일로 가장 먼저 도와주고 싶은 사람은 누구인가요?"

| 판정 (손으로) | 건수 |
|---|---|
| 뜻 유지 | 2 (F, I) |
| 뜻이 흐려짐 | 3 (C, H, K) |
| 뜻이 바뀜 | 6 (A, B, D, E, G, J) |

- 11건 모두 사실 검사를 통과해 AI 문장이 쓰였다. 사실 검사는 뜻이 바뀌었는지 보지 않는다.
- 바뀐 예:
  - B: "브랜드 디자인과 온라인 마케팅, 둘 중 어느 쪽을 가장 먼저 시작해 보고 싶으세요?"
  - G: "가장 먼저 도움을 청하고 싶은 사람은 누구인가요?" (대상이 반대가 됨)
  - A: 물음표로 끝나지 않음
- 지연은 p50 0.2~0.3초, p95 0.4~0.6초다.

### 4. 요약 빈 칸 채우기: Solar Pro (`exploreAi.fill`, 6건 × 2회)

| 항목 | 1회차 | 2회차 |
|---|---|---|
| 채운 칸 (요청 24칸) | 14 | 21 |
| 칸을 하나도 못 채운 사용자 | 2 (F, H) | 0 |
| 지연 p50 / p95 | 2.7초 / 5.9초 | 6.0초 / 6.1초 |
| 시간 초과 (15초) | 0 | 0 |

- 같은 입력이어도 실행마다 결과가 달랐다.
- 'target' 칸에 사람 대신 조언 문장을 쓰는 경우가 있었다. 예: C 의 "…선배 창업자나 멘토를 먼저 만나 … 들어보는 게 좋아요."

### 5. 공고 유형 분류 (30건)

| 방식 | 정답 유형과 같음 | 허용 유형까지 |
|---|---|---|
| 규칙 (지원 분야 → 유형) | 26 | **29** |
| Solar Mini 분류 (참고용으로만 시험) | 26~29 | 26~29 |

- **규칙이 틀린 예:**
  - 특강·세미나·포럼(P22·P23·P24)을 '상담'으로 분류했다. K-Startup 이 '멘토링·컨설팅·교육'을 한 분류로 묶어 보내기 때문이다.
  - 유형 필터가 분야 태그도 함께 보므로 교육 필터에는 나온다.
- **Solar 가 틀린 예:**
  - 유형 단어를 출력하지 않음 2건
  - 법률지원(P26)을 '지원사업'으로 분류
  - 시제품 제작센터(P29)를 '교육'으로 분류

## 판단과 권고

| 기능 | 판단 |
|---|---|
| **관련도 (Decide)** | **AI 유지·확대.** 규칙보다 P@3 가 4.7배 높고 빠르다. 창업 준비 결과의 추천에 Decide 를 연결할 것을 권한다. 규칙은 후보 거르기(마감·조건 불일치)와 Decide 실패 시 대체로 둔다. 운영 입력에 나이·거주지·사업자·원하는 도움을 함께 넣는다. |
| 추천 이유 (Solar Mini) | AI 유지. 사실 검사 탈락이 없고 빠르다. 프롬프트에 "제공 내용에 없는 조언을 더하지 않는다"를 더 세게 쓸 것을 권한다. |
| **질문 말투 (Solar Mini)** | **규칙 질문을 그대로 쓰도록 바꿀 것을 권한다.** 11건 중 6건이 뜻이 바뀌었다. AI 는 직전 답에 대한 짧은 반응 한 문장만 쓰고, 코드가 규칙 질문을 그 뒤에 붙인다. |
| 요약 칸 (Solar Pro) | AI 유지. 다만 실행마다 결과가 흔들린다. 지금처럼 'AI 제안·미검증'으로 표시하고, 빈 칸은 규칙 문장으로 둔다. |
| 유형 분류 | 규칙 유지. 비용 0이고 결과가 같다. '교육·특강·세미나·아카데미·포럼'이 제목에 있으면 교육을 먼저 두는 규칙 보완을 권한다. |

## 한계

- 자료가 작다(사용자 11명, 공고 30건, 후보 26건). 정답은 한 사람이 붙였다.
- Decide 후보는 26건(`DECIDE_MAX_CHOICES`)으로 줄였다. 운영 공고 111건 전체 순위가 아니다.
- 질문 뜻 판정은 손으로 했다.

# 모이소 기획안

## 한 줄 소개

부산·울산·경남에 흩어진 청년들의 실제 이동시간과 귀가 가능 시간을 계산해, 모두에게 가장 공평한 약속 장소를 추천하는 서비스.

## 해결하려는 문제

- 부·울·경은 하나의 생활권이지만 광역 이동에는 여러 교통수단을 함께 이용해야 한다.
- 지도상의 중간 지점과 실제 이동시간의 중간 지점이 다르다.
- 약속을 잡을 때 특정 사람에게 긴 이동시간과 환승 부담이 집중된다.
- 울산·경남 거주자는 막차 때문에 모임을 일찍 떠나야 하는 경우가 있다.

## 핵심 사용자

- 부산·울산·경남에 흩어져 사는 대학생과 청년
- 연합동아리, 프로젝트팀, 친구 모임, 커플

## 핵심 기능

1. 2~5명이 각자의 출발지를 입력한다.
2. 만나는 날짜와 귀가 희망 시간을 입력한다.
3. 주요 거점별 실제 이동시간과 환승 부담을 비교한다.
4. 가장 공평한 약속 장소 3곳을 추천한다.
5. 사람별 이동시간, 공평도 점수, 권장 귀가 시작 시간을 보여준다.

## 추천 기준

- 가장 오래 이동하는 사람의 이동시간
- 사람별 이동시간 차이
- 환승 횟수
- 마지막 귀가편을 놓칠 위험
- 역 주변에서 실제로 만날 장소가 있는지

## MVP 범위

### 반드시 구현

- 주요 출발 거점 선택
- 최적 약속 장소 계산
- 사람별 이동시간 비교
- 공평도 점수 표시
- 결과 공유 링크

### 여유가 있으면 구현

- 귀가 마감시간 안내
- 환승 횟수 반영
- 카페·식당 등 만남 장소 추천

### 구현하지 않음

- 회원가입 및 로그인
- 채팅과 친구 기능
- 결제 및 예약
- 전국 지역 지원

## 초기 지원 거점

- 부산: 부산역, 서면, 부전, 사상, 동래
- 울산: 울산역, 태화강, 삼산
- 경남: 창원중앙, 마산, 김해, 양산, 진주

## 화면 구성

1. **출발지 입력 화면** — 참여자별 출발지와 귀가시간 입력
2. **추천 결과 화면** — 추천 장소 3곳과 공평도 표시
3. **상세 비교 화면** — 사람별 이동시간·환승·귀가 가능 여부 비교
4. **공유 화면** — 결과 링크 복사

## 사용자 검증

- 부산·울산·경남 참가자 10명 이상에게 사용 요청
- 기존에 선택할 장소와 모이소 추천 장소 비교
- 추천 결과가 더 공평한지 질문
- 실제 사용할 의향과 개선 의견 수집

### 목표 지표

- 테스트 사용자 10명 이상
- 70% 이상이 기존 방식보다 공평하다고 응답
- 피드백을 반영해 추천 기준을 한 번 이상 수정

## 추천 트랙

**Track 1 — 지역과 사람을 연결하는 서비스**

## 발표 첫 문장

> 저희는 부산·울산·경남에 흩어진 청년들이 한 사람만 이동을 희생하지 않고 만날 수 있도록, 실제 이동시간을 기준으로 가장 공평한 약속 장소를 찾아주는 `모이소`를 만들었습니다.

## 핵심 원칙

- 기능을 늘리기보다 추천 한 번이 정확하게 동작하도록 만든다.
- 첫 버전을 빠르게 배포하고 실제 사용자 피드백을 받는다.
- 발표에서는 기술보다 문제, 해결 방식, 검증 결과를 강조한다.

# 주제 후보 (분석)

근거: [event-guide.md](event-guide.md), [ot-briefing.md](ot-briefing.md), [past-winners.md](past-winners.md).
전제: 행사 장소와 팀의 생활권·대학이 모두 **부산**이다.

## 순위

### ① 해운대시장 상인용 AI 다국어 메뉴·응대 웹 — 트랙: 스타트업 포럼 + 패스파인더

- **문제:** 해운대는 외국인 관광객이 많지만 시장 상인은 외국어 메뉴와 응대가 어렵다.
- **MVP:** 메뉴판 사진 → AI가 영·일·중 메뉴와 QR 페이지 생성 → 손님이 QR로 질문하면 번역 응대.
- **강점:** 로컬 비즈니스 성장 웹 서비스. 행사장에서 걸어갈 거리로 보이며(확인 필요) 행사 중 상인 3~5곳을 실제 사용자로 확보할 수 있다.
- **주의:** 외출은 1회 1시간 이내, 운영진에게 알린다.

### ② 부산 청년 전세 안전 진단 — 트랙: 패스파인더 + 코드포코리아

- **문제:** 대학가 자취생은 등기부등본을 읽기 어려워 위험 계약을 맺는다.
- **MVP:** 등기부·계약서 업로드 → 문서 파싱으로 근저당·선순위 추출 → 실거래가 API로 전세가율·위험 점수 → 쉬운 말 특약 체크리스트.
- **강점:** 대학 커뮤니티로 실제 사용자 확보. **주의:** 결과는 참고용이며 법률 자문을 대신하지 않는다고 표기.

### ③ 산복도로 독거노인 AI 안부전화 — 트랙: 코드포코리아

- **MVP:** 부산 사투리 음성 안부전화 → 기억력·말투·감정 신호 점수 → 복지 담당자 상담일지 자동 작성, 위험도 대시보드.
- **위험:** 울산대 '기억지기'와 겹쳐 독창성이 약하고, 행사 중 실사용자 확보가 어렵다.

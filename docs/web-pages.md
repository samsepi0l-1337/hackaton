# 웹 페이지 명세: 부산 청년 창업 길잡이

| 항목 | 내용 |
|---|---|
| 상위 문서 | [PRD](prd.md), [기능 명세](features.md) |
| 상태 | 초안 (팀 검토 전) |

> 이 문서는 **화면마다 무엇을 보여주고 무엇을 할 수 있는지** 정한다. 기능 규칙은 [기능 명세](features.md)의 ID(F0~F20)를 따른다. 디자인 시안·컴포넌트 구현은 설계 문서에서 정한다.

## 1. 페이지 목록

| # | 페이지 | 경로(가안) | 로그인 | 주요 기능 | 우선 |

| 1 | **메인** | `/` | 불필요 | F20 | P0 |

1~4가 핵심 페이지다. 5~8은 PRD 기능(로그인, 자동 제출, 통계)을 위해 필요한 부가 페이지다.

## 2. 공통

### 2.1 레이아웃

- **헤더:** 로고(메인으로), 메뉴 `공고 모음 · 상담 · 창업 유형 테스트`, 오른쪽에 `로그인` 또는 `내 정보`.
- **휴대폰(기본 기준, 360px~):** 메뉴는 햄버거로 접는다. 주요 버튼은 화면 아래에 고정한다.
- **푸터:** 개인정보 안내 요약, 데이터 출처(공공데이터포털 K-Startup), 오픈소스 라이선스 고지 링크.

### 2.2 공통 상태

| 상태 | 보여줄 것 |
|---|---|
| 로딩 | 카드·목록 자리 표시(스켈레톤). AI 응답은 "생각 중" 표시 후 스트리밍 |
| 빈 결과 | 이유 한 줄 + 다음 행동 버튼(예: 필터 초기화, 상담 시작) |
| 오류 | 무엇이 안 됐는지 + 다시 시도. AI 오류여도 규칙 결과는 보여준다 |
| 로그인 필요 | 로그인 화면으로 이동, 로그인 후 원래 화면으로 복귀 |

### 2.3 공통 요소

- **공고 카드:** 공고명, 기관, 지원 분야 태그, 지역 태그(부산/전국), 마감 D-day 배지(7일 이내 강조, 상시는 "상시"), 판정 배지(로그인+프로필이 있을 때: 가능/확인 필요).
- **원문 링크:** 공고가 나오는 모든 곳에 `원문 보기`(새 탭).

## 3. 메인 페이지 `/`

**목적:** 서비스가 무엇인지 3초 안에 알리고, 상담 또는 테스트로 보낸다.

| 순서 | 섹션 | 내용 | 행동 |
|---|---|---|---|
| 1 | 히어로 | 한 문장: "아이디어 한 줄이면, 지금 신청할 수 있는 부산 창업 지원사업을 찾아드려요" | `무료 상담 시작`(→ `/mentor`), `내 창업 유형 알아보기`(→ `/test`) |
| 2 | 숫자 | 지금 모집 중인 공고 N개, 이번 주 마감 N개 (F20) | |
| 3 | 마감 임박 공고 | 공고 카드 3개 (마감 임박순) | 카드 → 공고 상세, `전체 공고 보기`(→ `/programs`) |
| 4 | 이용 방법 | 3단계 그림: 사업 정보 입력 → AI 멘토 상담 → 지원사업 Top3·지원서 제출 | |
| 5 | 창업 유형 테스트 배너 | "1분 테스트로 내 창업 스타일 알아보기" | `/test` |
| 6 | 개인정보 안내 | "정보는 추천과 사용자가 승인한 지원서 제출에만 사용, 행사 후 삭제" | |

- 로그인한 사용자: 히어로 버튼을 `상담 이어서 하기`로 바꾸고, 최근 Top3 요약을 섹션 2 위에 보인다.

## 4. 공고 모음 페이지 `/programs`

**목적:** 흩어진 부산·전국 창업 지원 공고를 한곳에서 찾는다.

### 4.1 목록

| 영역 | 내용 |
|---|---|
| 검색창 | 공고명·기관·지원 내용 키워드 |
| 필터 | 지역(부산/전국), 지원 분야, 창업 단계, 대상 연령, 마감 기간(7일/30일/상시), 판정(로그인+프로필이 있을 때) |
| 정렬 | 마감 임박순(기본) / 최신 등록순 |
| 결과 수 | "모집 중 N개" |
| 목록 | 공고 카드, 20개씩 더 보기 |
| 안내 배너 | 로그인 안 했거나 프로필이 없으면: "상담을 하면 내가 지원 가능한지 바로 보여드려요" → `/mentor` |

- 휴대폰: 필터는 아래에서 올라오는 시트로 연다. 적용된 필터는 칩으로 보이고 하나씩 지울 수 있다.
- 필터·검색 상태는 URL에 넣어 공유·뒤로 가기가 된다.
- 마감 지난 공고는 기본으로 숨긴다. `마감 공고 보기` 토글.

### 4.2 공고 상세 `/programs/:id`

| 영역 | 내용 |
|---|---|
| 제목 | 공고명, 기관, D-day 배지 |
| 내 판정 | (로그인+프로필) `가능/확인 필요/불가` + 조건별 근거(나이 ✓, 창업 연차 ?, 지역 ✓) |
| 핵심 정보 | 접수 기간, 지역, 지원 분야, 신청 대상, 대상 연령, 창업 연차 |
| 지원 내용 | `support_ctnt` 원문 |
| 행동 | `원문 보기`, `이 사업으로 지원서 만들기`(→ `/apply/:id`, 로그인 필요), `이 사업 상담받기`(→ `/mentor`) |

## 5. 상담 페이지 (멘토링) `/mentor`

**목적:** 사업 정보를 폼으로 먼저 받고, 챗봇 멘토가 부족한 부분을 되물은 뒤 지원사업 Top3와 실행 계획을 준다.

### 5.0 진행 표시

화면 위에 단계 표시: `① 사업 정보 → ② 멘토 대화 → ③ 요약 → ④ 추천 결과`. 지난 단계는 눌러서 돌아갈 수 있다.

- 이전 상담이 있으면 첫 화면에 `이어서 하기 / 새 상담 시작` 선택 (F9).

### 5.1 ① 사전 상담 폼 (웹 폼)

챗봇 전에 **어떤 사업을 하고 싶은지, 타겟층이 누구인지** 세부 데이터를 받는다. 항목은 [기능 명세 F1](features.md#f1-사전-상담-폼-p0) 표를 따른다.

| 화면 | 섹션 | 대표 항목 |
|---|---|---|
| 1/3 | 나에 대해 | 나이, 창업 단계, 개업일, 사업장 지역(구), 소속, 팀 규모 |
| 2/3 | 하고 싶은 사업 | 아이디어 한 줄, 업종, 사업 형태, 해결하려는 문제, 준비 상태, 수익 방식 |
| 3/3 | 타겟 고객 | 고객 유형(B2C/B2B/B2G), 연령대, 고객 지역, 고객 설명, 지금 쓰는 대안, 필요한 지원 |

- 휴대폰에서 한 화면에 한 섹션. 아래에 `이전` / `다음` 고정 버튼, 마지막은 `멘토와 대화 시작`.
- 선택형은 버튼(칩)으로, 글자 입력은 남은 글자 수를 보인다.
- 필수 항목이 비면 `다음`을 눌렀을 때 그 항목으로 스크롤하고 붉게 표시한다.
- 조건부 항목: 창업 단계가 예비가 아니면 `개업일`, 고객 유형이 B2C면 `연령대`를 보인다.
- 창업 유형 테스트 결과가 있으면 섹션 1에 "내 유형: APDC" 칩으로 보인다.
- 섹션마다 자동 저장. "저장됨" 표시.

### 5.2 ② 멘토 대화 (챗봇)

| 영역 | 내용 |
|---|---|
| 상단 | 폼 요약 접이식 카드(아이디어, 고객, 업종). `수정`을 누르면 폼으로 |
| 대화창 | 멘토 첫 메시지: 폼 내용을 한 문장으로 다시 말하고 질문 1 |
| 질문 진행 | "질문 1/3" 표시. 답 입력창 + `건너뛰기` |
| 3개 완료 후 | `요약 보기` 버튼 고정. 자유 질문 계속 가능 |

- 응답은 스트리밍으로 표시. 보내는 중에는 입력창을 잠근다.
- 챗봇은 지원사업 이름·금액·마감일을 말하지 않는다(F2 규칙). 사용자가 물으면 "결과 화면에서 공고 데이터로 보여드릴게요"라고 답한다.

### 5.3 ③ 아이디어 1장 요약

- 항목 카드 5개: 문제 / 고객 / 해결책 / 수익 구조 / 부산 연결점. 항목마다 `수정`.
- 아래 `이 요약으로 지원사업 찾기` 버튼.

### 5.4 ④ 추천 결과

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 지원사업 Top3 | 공고 카드 + 판정 근거 + 추천 이유(이어서 표시) + `관련 있음/없음` + `지원서 만들기` + `원문 보기` |
| 2 | 찾아갈 기관 | 기관 카드 2~3개(이름, 주소, 하는 일, 링크) |
| 3 | 7일 실행 계획 | Day 1~7 체크리스트, 체크 상태 저장 |
| 4 | 설문 | "몰랐던 지원사업을 찾았나요?" 예/아니오 |
| 5 | 더 보기 | `조건 맞는 공고 전체 보기`(→ `/programs`에 판정 필터 적용) |

- Top3가 3개 미만이면 있는 만큼 보이고 공고 모음으로 안내한다.

## 6. 창업 유형 테스트 페이지 (MBTI형) `/test`

**목적:** 1분 테스트로 가볍게 유입하고 상담으로 이어지게 한다. 화면 이름은 "창업 유형 테스트"("MBTI"는 등록 상표, 공식 문항 사용 안 함).

### 6.1 시작 화면

- 제목, "12문항 · 약 1분", `테스트 시작` 버튼. 로그인 불필요.

### 6.2 문항 화면

- 한 화면에 한 문항, 큰 선택 버튼 2개. 누르면 바로 다음 문항.
- 위에 진행 막대(3/12), `이전` 버튼.
- 4개 축(A/P, S/T, D/H, C/K) × 3문항. 문항은 [기능 명세 F19](features.md#f19-창업-유형-테스트--mbti형-p1)를 따르고 팀이 새로 쓴다.

### 6.3 결과 화면

| 영역 | 내용 |
|---|---|
| 유형 | 4글자 코드(예: `APDC`) + 유형 이름 + 한 줄 설명 |
| 축별 결과 | 4개 막대(어느 쪽으로 몇 문항) |
| 강점·주의 | 강점 2개, 주의할 점 1개 |
| 잘 맞는 것 | 업종 예시, 먼저 보면 좋은 지원 분야(→ 해당 분야 필터가 적용된 `/programs`) |
| 행동 | `이 유형으로 상담 시작`(→ `/mentor`, 폼에 결과 자동 입력), `결과 공유`(링크 복사), `다시 하기` |
| 안내 | "재미·참고용 결과이며 지원 자격 판정에는 쓰지 않아요" |

- 로그인 안 했으면 결과를 브라우저에 두고, 로그인 후 계정에 저장한다.

## 7. 부가 페이지

### 7.1 로그인·가입 `/login`, `/signup`

- 가입: 이메일, 비밀번호, 개인정보 안내 동의 체크(필수). 로그인: 이메일, 비밀번호. 소셜 로그인 없음.
- 오류 문구: 이메일 형식, 비밀번호 8자 이상, 이미 가입된 이메일, 로그인 실패.

### 7.2 지원서 작성·제출 `/apply/:programId`

| 단계 | 화면 |
|---|---|
| 양식 준비 | "공고 양식을 가져오는 중" 진행 표시. 찾은 양식 파일 이름·신청 경로(웹/이메일) 표시 |
| 작성 | 양식 항목별 초안 카드(F13), 항목마다 수정·글자 수 표시. 신원 정보(이름, 연락처, 이메일)는 사용자가 입력 |
| 승인 | 제출할 값 전체 + 채운 양식 파일 미리 보기·내려받기 + "이 내용으로 제출합니다" 체크 + `승인하고 제출` |
| 진행 | 상태 단계 표시(입력 중 → 제출 중 → 완료), 실시간 갱신 (F16) |
| 사용자 조치 필요 | 이유 + `원문에서 직접 하기`(새 탭) + 채운 양식 파일 내려받기 + 입력값 복사 버튼 |
| 완료 | 접수 확인 캡처, 접수 번호, `제출 내역 보기`(→ `/me`) |
| 실패 | 실패 이유 + `다시 시도`(1회) |

### 7.3 내 정보 `/me`

- 제출 내역 목록(F17), 지난 상담 목록(이어서 하기), 창업 유형 결과, 로그아웃, 계정 삭제(확인 대화상자).

### 7.4 팀 통계 `/admin`

- F14 지표 숫자 카드. 팀 계정만.

## 8. 페이지 이동

```text
메인 ─┬─ 무료 상담 시작 ──→ (로그인) ─→ 상담 ①폼 → ②챗봇 → ③요약 → ④결과
      ├─ 창업 유형 테스트 ─→ 결과 ─→ 이 유형으로 상담 시작 ─→ 상담 ①폼(자동 채움)
      └─ 마감 임박 공고 ──→ 공고 상세
공고 모음 ─→ 공고 상세 ─→ 지원서 만들기 ─→ (로그인) ─→ 지원서 작성 → 승인 → 제출 진행 → 완료
상담 ④결과 ─→ 지원서 만들기 ─→ 지원서 작성 …
완료 ─→ 내 정보(제출 내역)
```

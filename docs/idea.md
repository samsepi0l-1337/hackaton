# 주제 후보

## 선정 기준

1. 부산 대학생인 **내가 직접 겪는 문제**
2. **하루 안에 만들 수 있는 크기**: 입력 하나 → 국산 AI → 결과 화면 하나
3. 행사장의 부울경 청년 약 100명이 **바로 사용자**가 될 수 있음
4. 동남권(부산) 특화 + 국산 AI 활용

## 한눈에 비교

| 기준           | 1. 부산 청년정책 맞춤 비서          | 2. 학생회–동네 가게 제휴 매칭          |
| -------------- | ----------------------------------- | -------------------------------------- |
| 내가 겪는 문제 | 받을 수 있는 지원을 몰라서 놓침     | 제휴 가게를 발로 뛰어 구함             |
| 부산 특화      | 높음 (부산시·구청·대학 정책 데이터) | 중간~높음 (동백전 가맹점, 부산 대학가) |
| 국산 AI 필요성 | 높음 (공고 PDF 읽기 + 근거 답변)    | 중간 (소개글·제안서 작성)              |
| 구현 난이도    | 낮음 (단면 서비스)                  | 중간 (양면 서비스)                     |
| 행사 중 사용자 | 매우 쉬움 (참가자 전원)             | 가게 섭외가 변수                       |
| 맞는 트랙      | 패스파인더, 코드포코리아            | 스타트업 포럼, 패스파인더              |

**추천: 1번.** 구현 위험이 낮고 사용자 수치를 확실히 만들 수 있다. 로컬 비즈니스 트랙을 노리고 가게 섭외 인원이 있으면 2번.

## 1. 부산 청년정책 맞춤 비서

### 한 문장

부산 대학생이 질문 6개에 답하면, 부산시·구청·대학의 청년 지원 중 **지금 받을 수 있는 것**과 마감일, 준비 서류를 근거와 함께 알려준다.

### 사용자

| 사용자                                | 상황                             | 원하는 것                    |
| ------------------------------------- | -------------------------------- | ---------------------------- |
| 자취하는 3학년 (타지 출신, 부산 전입) | 월세가 부담되고 지원 여부를 모름 | "나 월세 지원 받을 수 있어?" |
| 취업 준비 4학년·졸업생                | 자격증 응시료, 면접 비용 부담    | 취업 관련 지원 한 번에 보기  |
| 휴학생                                | "휴학생도 되나?"가 공고마다 다름 | 내 상태로 되는지 판정        |

### 화면

1. **질문**: 출생연도, 사는 구(16개 구·군), 학적(재학/휴학/졸업/미진학), 거주 형태(자가/자취·월세/기숙사), 소득 구간(모름 가능), 관심 분야(주거/교통/취업/문화/금융)
2. **결과**: ✅받을 수 있음 / 🟡확인 필요 / ❌해당 없음 카드 목록. 카드마다 지원명, 금액, D-day, 판정 이유 한 줄
3. **상세**: 쉬운 말 요약 3줄, 자격 조건별 ✅/❌ 표, 준비 서류 체크리스트, 신청 방법, 원문 링크
4. **질문하기**: "휴학생도 돼요?" → 해당 공고 원문을 인용해 답변

### 동작 구조

자격 판정은 LLM이 아니라 **코드**가 한다. LLM은 공고 구조화와 설명만 한다. 빠르고 일관되며 시연 중 오답 위험이 낮다.

```text
[미리 1회] 공고 PDF/웹 → Upstage Document Parse → Solar(JSON 추출)
  → policies: {이름, 기관, 금액, 나이_최소, 나이_최대, 거주요건(구 목록),
               학적요건, 소득요건, 거주형태요건, 마감일, 서류[], 신청방법, 원문텍스트, 링크}
[사용자] 답변 6개 → 코드로 조건 비교 → ✅/🟡/❌ (조건 값이 비면 🟡)
[설명]   Solar: 판정 결과 + 원문 → 쉬운 말 요약, 이유 한 줄
[질문]   Solar: 질문 + 해당 공고 원문 → 원문 인용 답변 (원문에 없으면 "공고에 없음")
```

### 데이터

- 출처: 온통청년 청년정책 Open API(지역=부산), 부산시 청년 정책 포털, 구청 공고, 학교 장학·지원 공지 (_API 범위·포털 주소 확인 필요_)
- 양: 20~30개. 학교 자체 지원을 넣으면 다른 서비스에 없는 데이터가 된다.
- 검수: 추출 결과에서 금액·나이 오류만 사람이 확인 (30분)

### 사용자 확보와 수치

- 배포 URL·QR을 행사 오픈채팅, 학교 커뮤니티, 학과 단톡방에 공유
- 결과 화면 하단: "몰랐던 지원을 찾았나요? (예/아니오)"
- **발표 숫자**: 사용자 N명, 몰랐던 지원 발견 비율 M%, 1인당 받을 수 있는 지원 평균 K개(금액 합계)

### 발표 2분

1. "부산 청년이 받을 수 있는 지원이 수십 개인데, 저도 제가 뭘 받을 수 있는지 몰랐습니다."
2. 문제: 공고가 시·구·학교로 흩어져 있고 조건이 PDF에 숨어 있다.
3. 해결: 질문 6개 → 내 지원 목록 (화면 1장)
4. 검증: 하룻밤 N명, M%가 몰랐던 지원 발견
5. 확장: 울산·경남 정책, 마감 알림

### 시연 4분

심사위원이 나이·구 직접 입력 → 카드 목록 → 월세 지원 상세(조건별 ✅/❌) → "휴학생도 돼요?" → 원문 인용 답변 → 사용 통계 화면

### 위험과 대응

| 위험                    | 대응                                                          |
| ----------------------- | ------------------------------------------------------------- |
| 추출 오류로 잘못된 판정 | 코드 판정 + 사람 검수, 애매하면 🟡 "확인 필요"                |
| 공고 마감·변경          | 수집 날짜 표시, "원문에서 최종 확인" 안내                     |
| 비슷한 전국 서비스 존재 | 부산 구청·학교 지원 + 조건별 판정 + 원문 근거 답변으로 차별화 |

## 2. 학생회–동네 가게 제휴 매칭 (동백전 연계)

### 한 문장

학생회가 행사 정보를 넣으면, 학교 앞 **동백전 가맹점** 중 맞는 가게와 제휴 제안서를 AI가 만들어 주고, 가게는 학생 단체 손님과 동백전 결제를 얻는다.

### 부산 특화 포인트

- **동백전**(부산 지역화폐) 가맹점만 추천 → "학생은 할인 + 캐시백, 돈은 부산 가게로" (_캐시백 비율·가맹점 데이터 공개 여부 확인 필요_)
- **부산 대학가**: 부산대(장전동), 경성대·부경대(대연동), 동아대(하단) 상권
- 피칭: "학생 행사 예산이 프랜차이즈가 아니라 부산 동네 가게로 가게 한다."

### 사용자

| 사용자             | 지금 하는 일                               | 원하는 것                          |
| ------------------ | ------------------------------------------ | ---------------------------------- |
| 학생회·동아리 임원 | MT·개총 장소와 제휴를 직접 돌아다니며 구함 | 조건 맞는 가게와 제안서를 빠르게   |
| 대학가 가게 사장님 | 학생 단체 손님을 원하지만 연락 경로가 없음 | 제안을 받고 "수락"만 누르기        |
| 일반 학생          | 제휴 혜택을 몰라서 못 씀                   | 학교 앞 제휴 쿠폰을 한 곳에서 보기 |

### 화면

1. **학생회 요청**: 행사 종류(개총/MT/뒤풀이/간식 행사), 인원, 1인 예산, 날짜, 학교
2. **추천 결과**: 가게 3곳 — 맞는 이유(수용 인원, 예산 내 메뉴, 거리), 예상 총액, 동백전 결제 혜택
3. **제안서**: Solar가 가게별 맞춤 제안서 작성(행사 개요, 인원, 희망 할인, 가게가 얻는 것) → 수정 후 보내기
4. **사장님 화면**: 받은 제안 → 수락/조건 수정 → 수락 시 제휴 쿠폰 페이지·QR 자동 생성, 일반 학생에게 공개

### 동작 구조

```text
[미리] 가게 10~15곳 직접 입력: {이름, 위치, 좌석수, 대표메뉴·가격, 단체가능, 동백전가맹, 연락처}
       → Solar: "가게 소개 + 학생 단체 추천 메뉴" 자동 작성
[요청] 학생회 입력 → 코드 필터(좌석 ≥ 인원, 예산 ≥ 메뉴가) → Solar 순위·이유 작성
[제안] Solar: 행사 + 가게 정보 → 제안서 초안
[수락] 사장님 수락 → 쿠폰 페이지·QR 생성 → 사용 횟수 집계
```

### 사용자 확보와 수치

- 학생회 쪽: 본인 학교 학생회·동아리 임원 2~3명이 실제 다음 행사로 요청
- 가게 쪽: 행사장 근처나 학교 앞 가게 3곳에 전화·방문으로 "수락" 요청 (외출 1회 1시간 이내, 운영진에게 알림)
- **발표 숫자**: 제안서 생성 N건, 가게 수락 M건, 제안서 작성 시간 "평균 30분 → 1분"

### 발표 2분

1. "학생회 하면서 제휴 가게를 찾느라 며칠을 돌아다녔습니다."
2. 문제: 학생 행사 예산은 큰데 동네 가게와 연결되는 경로가 없다.
3. 해결: 행사 정보 → 동백전 가맹점 추천 → 제안서 → 사장님 수락
4. 검증: 실제 학생회 요청 N건, 가게 수락 M건
5. 확장: 부산 전 대학가, 동백전 캐시백 데이터 연계

### 시연 4분

"개강총회 40명, 1인 1만5천원, 경성대" 입력 → 추천 3곳 → 제안서 생성 → 사장님 화면에서 수락 → 쿠폰 QR을 심사위원 휴대폰으로 스캔

### 위험과 대응

| 위험                             | 대응                                                           |
| -------------------------------- | -------------------------------------------------------------- |
| 하룻밤에 실제 가게 수락이 어려움 | 아는 가게 1곳이라도 확보, 나머지는 "협의 중"으로 정직하게 표시 |
| 동백전 데이터 접근 불가          | 가맹 여부 직접 입력, 피칭에서 "연계 계획"으로 제시             |
| 양면 플랫폼이라 화면이 많음      | 사장님 화면은 "수락 버튼 하나"로 최소화                        |

## 공통 기술 스택

- **웹**: Next.js (App Router) + Vercel 배포 (공개 URL)
- **DB**: Supabase 또는 JSON 파일
- **국산 AI**: Upstage Document Parse (문서 읽기), Solar (추출·요약·근거 답변·작성) — OpenAI 호환 API
- **지도 (2번)**: 카카오맵 JS SDK, 막히면 주소 텍스트
- **보안**: API 키는 서버 라우트에만, 개인정보는 저장하지 않음

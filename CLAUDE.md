# hackaton

This repository is a hackathon project (ICT INNOHACK 2026, 2026-11-27 to 2026-11-28).
Speed is more important than process. This workflow replaces the personal defaults for this repository.

## Workflow

- Make a branch and a pull request for each change. A pull request is permitted and recommended.
- CI/CD is not mandatory. Do not add a CI check, a required status check or a merge queue as a merge condition.
- Do not wait for CI before you merge. A merge does not need a CI result.
- Do not add a CI runner, a deployment pipeline or a branch protection rule unless the user asks for it.
- An independent review is optional. Do it only when the user asks for it.
- Run the local tests or the app before you merge, when this is fast.

## Scope

- Make only the features that the demo needs. Remove features that the demo does not need.
- All code must be written during the hackathon. You can use AI tools.
- Obey the open-source licenses and show the license notices.
